MailBridge 0.9.8 — Windows x64

ПЕРВАЯ УСТАНОВКА
Постоянная ссылка: https://github.com/okkiam/mailbridge-releases/releases/latest/download/MailBridge-Setup.exe
Откройте установщик и сохраните предложенную папку. Программа ставится текущему пользователю; Python, Office, Codex и ключ OpenAI API отдельно не нужны.
Испытана Windows 11 x64 на первом ПК. Windows 10, корпоративные домены и второй ПК проверяются отдельно.

ИНТЕРФЕЙС
При запуске открывается «Главная MailBridge»: текущий ящик, быстрые действия, незавершённые исходящие, изменения версии и почта для связи. «Назад» возвращает сюда. Разделы находятся во вкладках сверху. Ящики, исходящие, подписи, удаление, обновления, подключение ChatGPT, справка и диагностика открываются внутри главного окна. Введённый текст сохраняется при переходе между вкладками; перед закрытием открытых редакторов появляется предупреждение.
Адрес разработчика закреплён внизу главной страницы. Для переходов, раскрытия списков и прокрутки откройте «Справка» → «Анимации интерфейса». Исходный режим — «Как в Windows». Выбор «Всегда включены» или «Выключены» действует только в MailBridge.

НАСТРОЙКА MAIL.RU
1. В безопасности Mail.ru откройте «Внешние сервисы» и включите «Доступ к Почте по IMAP, POP и SMTP».
2. В «Паролях для внешних приложений» создайте пароль MailBridge с правами «Полный доступ к Почте» для чтения и отправки. Для режима только чтения достаточно IMAP/POP3, но такой пароль может не разрешать SMTP.
3. Сохраните сгенерированный секрет в своём менеджере паролей. В MailBridge вводится именно код, а не название записи и не пароль сайта. В чат секрет не отправляйте.
4. Откройте MailBridge через ярлык, введите полный адрес и код, подтвердите выбор ящика.
5. «Проверить подключение» проверяет почтовый доступ и счётчик Входящих, ничего не сохраняя. «Сохранить и подключиться» сначала проверяет и при успехе сохраняет адрес/пароль. Пустое поле пароля при прежнем адресе использует сохранённую запись.
При этой проверке проверяется IMAP; SMTP отдельно проверяется при отправке. Соединение не остаётся постоянно открытым.

НЕСКОЛЬКО ЯЩИКОВ
Кнопка «Добавить» позволяет подключить ещё один ящик, сохранив остальные. У каждого ящика свой пароль в Windows. Для переключения используйте список «Текущий ящик»; заново вводить пароль не нужно. Подключение нового адреса сохраняется после успешной проверки.
В запросе ChatGPT называйте адрес: «В ящике name@mail.ru найди…». Если подключено несколько ящиков и адрес неясен, помощник должен уточнить выбор. Результаты разных ящиков разделяются.
Подготовленное письмо сохраняет исходного отправителя, даже если позже переключить ящик. Адрес показан в просмотре и списке исходящих. «Отключить ящик» удаляет доступ только к выбранному адресу, остальные сохраняются.

ПОДПИСИ
Выберите нужный ящик и нажмите «Подписи». Можно сохранить несколько вариантов: вступление, имя, должность, телефон, почту, адрес, сайт и дополнительный текст. Цвет имени выбирается из именованных кнопок или в окне «Другой цвет…» с образцом; PNG-логотип до 512 КиБ и 1024 × 1024 встраивается в письмо без внешней загрузки.
Отметьте вариант по умолчанию или выбирайте подпись в окне нового письма. В ChatGPT можно попросить применить конкретную подпись или подготовить письмо без неё. Подпись добавляется в конец полного текста, в том числе при подготовке пересылки; не вставляйте её второй раз вручную.
Подпись входит в полный предварительный просмотр. Кнопка «Посмотреть оформление подписи» показывает сохранённый вариант. Почтовый клиент получателя может отобразить оформление иначе или выбрать текстовую версию. Редактор произвольного HTML и импорт подписи из изображения не предусмотрены.
Изменение шаблона не меняет уже подготовленные письма. Шаблоны сохраняются локально под защитой Windows.

ПОДКЛЮЧЕНИЕ CHATGPT
Нужен установленный ChatGPT с «Работой» и доступом к этому компьютеру.
MailBridge → «Подключить ChatGPT» → «Подключить в ChatGPT». Подтвердите установку карточки плагина; в новом чате выберите @MailBridge.
Примеры: «Покажи папки моей почты», «Найди письма себе», «Сделай сводку за неделю», «Подготовь ответ на это письмо».
Плагин каждый раз находит актуальную установленную программу. Длинный запрос с путями повторять не требуется. Во вкладке «Запрос для одного чата» есть запасной вариант.
Кешированная карточка старого плагина может показывать прежнее описание. Его bootstrap 0.1.0 продолжает читать текущую инструкцию приложения; исходный пакет 0.3.0 обновляет описание при обычном подтверждении установки в ChatGPT.
Разрешение на локальный запуск даёт сам ChatGPT штатным способом. MailBridge не меняет политики, не выдаёт разрешения за пользователя и не добавляет почтовый MCP.

ЧТЕНИЕ И ВЛОЖЕНИЯ
Папки проверяются отдельно: Входящие, Письма себе, Отправленные и другие. Чтение сохраняет флаги прочитанности. Пагинация и ограничения выдачи показываются явно.
Поддержаны PDF, DOCX, XLSX, PPTX, DOC, XLS, RTF, TXT/CSV и другие текстовые файлы, EML и выбор файлов из ZIP. OCR сканов и изображений на русском/английском работает локально и включён в установщик. Office и отдельный OCR устанавливать не требуется. Вёрстка и сложные таблицы отдельно не подтверждаются, формулы не пересчитываются. DOC читается частично: основной текст. Макросы не выполняются.
Нужные письма и извлечённый текст попадают в контекст ChatGPT. Модель не становится локальной.

ИСХОДЯЩИЕ
ChatGPT может подготовить новое письмо, ответ или явно запрошенный ответ всем. По умолчанию MailBridge открывает локальный просмотр; отдельно доступен режим подтверждения в чате, описанный ниже.
Перед отправкой проверьте От/Кому/Копия/Скрытая копия, тему, полный текст и все вложения. Вложения фиксируются при подготовке: изменение исходного файла позже не меняет уже показанную копию.
При подтверждении в окне поставьте галочку проверки и сами нажмите «Отправить письмо». Агент не подтверждает отправку за вас. Любая правка требует новой подготовки и нового просмотра.
Можно подготовить новое письмо и без ChatGPT: «Исходящие письма» → «Новое письмо».
Локальные исходящие защищены Windows DPAPI; это не серверные черновики. Результат доступен в том же окне и списке исходящих.
«Письмо отправлено. Почтовый сервер принял его для доставки» появляется только после подтверждения сервером. При отказе — «Не отправлено» с причиной и доступным кодом. При «Результат требует проверки» подтверждение могло потеряться из-за обрыва связи: не повторяйте автоматически, проверьте папки и адресата. Автоматического повтора и скрытой отправки части адресатов при отказе остальных нет.
«Проверить отчёты о доставке» ищет связанные структурированные уведомления во Входящих: о доставке, недоставке или задержке. Проверяется до 200 последних писем с дня перед подготовкой, отчёт до 1 МиБ. Результат показывает область проверки и конкретных получателей. Отчёты могут прийти позже, оказаться в другой папке или не прийти; отсутствие отчёта не доказывает доставку. Подлинность автора отчёта независимо не проверяется, прочтение человеком не отслеживается. Уведомления запрашиваются, только если сервер поддерживает эту возможность.
«Проверить Отправленные» только ищет серверную копию по Message-ID. Если копия не найдена, она может появиться позже. Отдельное «Сохранить копию» после просмотра создаёт копию в показанной папке, не отправляет письмо повторно.
Лимиты: до 50 получателей, 100000 символов тела, 10 вложений, каждый и суммарно до 25 МиБ, готовое MIME-письмо до 36 МиБ; дополнительно учитывается лимит SMTP-сервера. Не-ASCII имя перед @ (SMTPUTF8), HTML-редактор и серверные черновики пока не поддержаны.

ОБНОВЛЕНИЯ
MailBridge → «Обновления» → «Проверить обновления». Программа проверяет цифровую подпись сведений о выпуске; новый установщик сверяется по подписанным размеру и SHA-256. До проверки он не запускается.
Нажмите «Обновить» после просмотра изменений. Окно закроется; помощник дождётся завершения почтовых команд, заменит одну установку, проверит запуск и откроет программу снова. Настройки и история исходящих остаются отдельно.
Во время загрузки видны полоса, проценты, скачанный объём и средняя скорость. Можно нажать «Отменить загрузку»: программа дождётся текущего сетевого запроса и остановит обновление до установки. Скорость зависит от соединения; проверка пакета обозначается отдельным этапом.
При запуске MailBridge проверяет сведения о выпуске в фоне. Если доступна новая версия с подтверждённой подписью, слева от переключателя темы появляется плашка. «Подробнее» открывает раздел обновлений. При недоступности сети программа продолжает работу; проверить повторно можно вручную. Установка начинается только после вашего согласия.
В окне есть «Восстановить предыдущую версию». Старая версия может не поддерживать новые функции, но повторной отправки писем не будет.
При нескольких подключённых ящиках восстановление версии старше 0.9.4 блокируется, поскольку она не понимает новый список ящиков. Настройки остаются на месте.
При недоступности GitHub установленная программа продолжает работать. Почтовые данные и пароли не отправляются на GitHub.
Эта проверка подписи обновления отличается от доверенной подписи издателя Windows. Доверенной подписи издателя Windows пока нет. SmartScreen может показывать предупреждение, а Smart App Control или корпоративная политика — блокировать запуск. Совместимость с включённым Smart App Control не подтверждена. Не отключайте защиту ОС ради установки.

ДАННЫЕ И ДИАГНОСТИКА
Пароль хранится в Credential Manager. «Отключить ящик» удаляет только текущую почтовую настройку/пароль MailBridge после вашего подтверждения; письма на сервере остаются.
Удаление программы сохраняет настройки, пароль и защищённые локальные исходящие. DPAPI-данные привязаны к Windows-пользователю; переносить их на другой ПК вместо отдельной настройки нельзя.
«Диагностика» показывает версию, ОС, TLS и результат обновления без пароля и тел писем. Отчёт можно сохранить локально и передать разработчику после просмотра.
Окно настройки не нужно держать открытым для чтения из ChatGPT. При режиме подтверждения в окне откроется отдельный просмотр; в режиме чата окно можно держать закрытым.

Подробности выпуска: https://github.com/okkiam/mailbridge-releases/releases

ДЛИННЫЕ ФАЙЛЫ И СКАНЫ
Вложение до 50 МиБ, входящее MIME-письмо до 100 МиБ, PDF до 1000 страниц. Текст возвращается частями: по умолчанию 20000 символов и 10 страниц за вызов, с возможностью продолжения. До 8 млн символов за обрабатываемый документ/порцию страниц. Чтение выполняется в отдельном процессе до 120 секунд / 1 ГиБ; при превышении предложите разделить файл.
Можно попросить: «Прочитай вложенный скан, укажи сроки и номера страниц; если документ длинный, дочитай все части». Ошибки OCR возможны: суммы, реквизиты, даты и имена сверяйте с оригиналом. Картинка страницы PDF может быть сохранена для визуального изучения; это не заменяет фактический просмотр.
ZIP/EML открываются для выбора нужного файла, автоматического запуска вложений нет. RAR/7z, старый PPT, аудио/видео и все существующие форматы не поддерживаются. Доступные возможности и предупреждения сообщает коннектор.
Распознанный текст кешируется под защитой Windows DPAPI (до 256 МиБ, 100 записей, 7 дней). Файлы, сохранённые в папке чата, не шифруются приложением автоматически.
Лицензии компонентов находятся в app/licenses/reader-LICENSES.zip; соответствующие открытые исходники libiconv и рецепт сборки доступны в файле third-party-source.zip того же выпуска.
УДАЛЕНИЕ ЧЕРЕЗ CHATGPT
Пример: «Найди письма от указанного отправителя за 2026 год, покажи список и подготовь перемещение в Корзину». Агент выбирает точные письма и показывает полный список в выбранном режиме подтверждения; браузером почты он не управляет.
При подтверждении в окне проверьте ящик, исходную папку, Корзину, число и весь список. Поставьте галочку и сами нажмите «Переместить в Корзину». Окно MailBridge до этого можно держать закрытым: агент откроет его по необходимости. Агент не нажимает подтверждение за вас.
Кнопка «Удаление писем» открывает историю и подготовленные просмотры. «Проверить результат» уточняет результат без повторного перемещения. При неизвестном/частичном исходе автоматического повтора нет. Предпросмотр действует 24 часа; партия до 500 писем одной папки.
Это перемещение в Корзину по IMAP, не безвозвратное удаление. Корзина не очищается; освобождение места не гарантируется сразу. Восстановление письма средствами самой почты возможно, пока копия находится в Корзине; отдельной кнопки восстановления писем в MailBridge пока нет. «Восстановить предыдущую версию» относится к программе, не к письмам.

ОБЪЁМ ПИСЕМ
Примеры: «Покажи топ-10 отправителей в Рассылках по мегабайтам и по количеству, с долями»; «Сколько объёма занимают письма в каждой папке моего ящика?». ChatGPT получает сводку, рассчитанную MailBridge по отправителям и серверным размерам, без чтения тел и скачивания вложений.
Большая выборка дочитывается порциями. Промежуточный рейтинг помечается как неполный; готовый отчёт указывает папки/период/полноту. Копии в разных папках считаются отдельно; весь ящик включает также Отправленные, Спам и Корзину. Снимки по папкам последовательные, не одновременные.
MB = 1000000 байт. Это заявленный IMAP-сервером размер целого MIME-письма, не фактический диск/квота Mail.ru и не размер распакованных файлов. Доли относятся к обработанной выборке. До 50000 писем одной папки, до 250000 за отчёт; при превышении нужно сузить период/папки. Кеш отчётов защищён Windows DPAPI, до 7 дней/последние 20; продолжение действительно 24 часа.

ПЕРЕХОД СО СТАРОЙ ВЕРСИИ
Если стоит 0.5.1 и в ней ещё нет «Обновлений», один раз запустите новый установщик поверх прежней установки, сохранив её папку. Для версии 0.6.0 и новее доступна кнопка обновления из приложения. Настройки и пароль должны сохраниться. Испытание новой версии на втором реальном ПК остаётся отдельным шагом.

Исправлены прокрутка над полями, первый щелчок по кнопкам в длинных формах и освобождение ресурсов. Возможности почты, документов, подписей, обновления и истории сохранены.

ИЗМЕНЕНИЯ 0.9.3
Текст справки переносится по доступной ширине, включая окна с полосой прокрутки. Кнопка «Подключить в ChatGPT» совпадает с фоном панели в обеих темах. Для ярлыков, поиска Windows и окна приложения используется один рисунок конверта во всех размерах.
Кнопки проверки и сохранения доступны в уменьшенном окне. В справке, текстах и списках работают колесо и перетаскивание ползунка. Диагностика показывает окно сразу и заполняет отчёт по мере готовности.
Во время проверки подключения светлая часть полоски движется до получения ответа Mail.ru. Движение можно выключить флажком «Анимация проверки». Выбор темы и анимации сохраняется на этом ПК.
Почтовые возможности, настройки и история операций сохраняются. Отправка и перенос в Корзину по-прежнему требуют вашего просмотра и подтверждения.
Если MailBridge уже установлен, используйте «Обновления» → «Проверить обновления» → «Обновить».

ПОДТВЕРЖДЕНИЕ В ЧАТЕ (ДОПОЛНИТЕЛЬНЫЙ РЕЖИМ)
Откройте «Подключение ChatGPT» → «Подтверждение действий» → «Разрешить подтверждение в чате» и прочитайте пояснение. По умолчанию остаётся подтверждение в окне. Текущий режим отмечен цветной кнопкой, галочкой и словом «включено», а над кнопками приведено его описание. Настройка относится ко всем ящикам этого профиля; её можно отключить там же.
После подготовки ChatGPT показывает точных получателей, полное письмо с подписью и все вложения либо весь список писем для Корзины. Только после отдельного явного ответа человека выполняется действие. Изменение письма или списка требует нового просмотра и подтверждения. Просмотр для чата действует 15 минут и используется один раз.
MailBridge не видит сам ответ человека и доверяет ChatGPT соблюдение этого правила. Неправильное понимание ответа или влияние инструкций из чужого письма могут привести к нежелательному действию. Одноразовый просмотр защищает от изменения содержания и повторного выполнения той же операции, но не доказывает согласие человека. Для более строгого контроля используйте подтверждение в окне.
Работает только в чате ChatGPT с разрешённым локальным выполнением на этом ПК и актуальной инструкцией MailBridge. Установка приложения сама по себе не даёт доступ обычному чату. Отдельное сохранение копии в «Отправленные» по-прежнему подтверждается в окне. Удаление означает перенос в Корзину, без её очистки.

ЕСЛИ WINDOWS БЛОКИРУЕТ ЗАПУСК
При ошибке загрузки компонента программа по возможности показывает его имя и код Windows. Сохраняется технический отчёт без почты и пароля: %LOCALAPPDATA%\MailBridge\diagnostics\startup-error.json. Если заблокирован сам запуск приложения, создать отчёт может быть невозможно.
Для ошибки политики загрузки DLL откройте «Просмотр событий» → «Журналы приложений и служб» → Microsoft → Windows → CodeIntegrity → Operational. Найдите событие во время запуска MailBridge и передайте разработчику имя заблокированного файла и код. Для обнаружений антивируса используется «Журнал защиты» Windows. Не отключайте защиту ради запуска и не считайте сообщение о недоверенном приложении доказательством обнаруженного вируса.
