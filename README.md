MailBridge 0.8.1 — Windows x64

ПЕРВАЯ УСТАНОВКА
Постоянная ссылка: https://github.com/okkiam/mailbridge-releases/releases/latest/download/MailBridge-Setup.exe
Откройте установщик и сохраните предложенную папку. Программа ставится текущему пользователю; Python, Office, Codex и ключ OpenAI API отдельно не нужны.
Испытана Windows 11 x64 на первом ПК. Windows 10, корпоративные домены и второй ПК проверяются отдельно.

НАСТРОЙКА MAIL.RU
1. В безопасности Mail.ru откройте «Внешние сервисы» и включите «Доступ к Почте по IMAP, POP и SMTP».
2. В «Паролях для внешних приложений» создайте пароль MailBridge с правами «Полный доступ к Почте» для чтения и отправки. Для режима только чтения достаточно IMAP/POP3, но такой пароль может не разрешать SMTP.
3. Сохраните сгенерированный секрет в своём менеджере паролей. В MailBridge вводится именно код, а не название записи и не пароль сайта. В чат секрет не отправляйте.
4. Откройте MailBridge через ярлык, введите полный адрес и код, подтвердите выбор ящика.
5. «Проверить подключение» проверяет почтовый доступ и счётчик Входящих, ничего не сохраняя. «Сохранить и подключиться» сначала проверяет и при успехе сохраняет адрес/пароль. Пустое поле пароля при прежнем адресе использует сохранённую запись.
При этой проверке проверяется IMAP; SMTP отдельно проверяется при отправке. Соединение не остаётся постоянно открытым.

ПОДКЛЮЧЕНИЕ CHATGPT
Нужен установленный ChatGPT с «Работой» и доступом к этому компьютеру.
MailBridge → «Подключить ChatGPT» → «Подключить в ChatGPT». Подтвердите установку карточки плагина; в новом чате выберите @MailBridge.
Примеры: «Покажи папки моей почты», «Найди письма себе», «Сделай сводку за неделю», «Подготовь ответ на это письмо».
Плагин каждый раз находит актуальную установленную программу. Длинный запрос с путями повторять не требуется. Во вкладке «Запрос для одного чата» есть запасной вариант.
Кешированная карточка старого плагина может показывать прежнее описание. Его bootstrap 0.1.0 продолжает читать текущую инструкцию приложения; исходный пакет 0.2.0 обновляет описание при обычном подтверждении установки в ChatGPT.
Разрешение на локальный запуск даёт сам ChatGPT штатным способом. MailBridge не меняет политики, не выдаёт разрешения за пользователя и не добавляет почтовый MCP.

ЧТЕНИЕ И ВЛОЖЕНИЯ
Папки проверяются отдельно: Входящие, Письма себе, Отправленные и другие. Чтение сохраняет флаги прочитанности. Пагинация и ограничения выдачи показываются явно.
Поддержаны PDF, DOCX, XLSX, PPTX, DOC, XLS, RTF, TXT/CSV и другие текстовые файлы, EML и выбор файлов из ZIP. OCR сканов и изображений на русском/английском работает локально и включён в установщик. Office и отдельный OCR устанавливать не требуется. Вёрстка и сложные таблицы отдельно не подтверждаются, формулы не пересчитываются. DOC читается частично: основной текст. Макросы не выполняются.
Нужные письма и извлечённый текст попадают в контекст ChatGPT. Модель не становится локальной.

ИСХОДЯЩИЕ
ChatGPT может подготовить новое письмо, ответ или явно запрошенный ответ всем; MailBridge открывает локальный просмотр.
Перед отправкой проверьте От/Кому/Копия/Скрытая копия, тему, полный текст и все вложения. Вложения фиксируются при подготовке: изменение исходного файла позже не меняет уже показанную копию.
Поставьте галочку проверки и сами нажмите «Отправить письмо». Агент не подтверждает отправку за вас. Любая правка требует новой подготовки и нового просмотра.
Можно подготовить новое письмо и без ChatGPT: «Исходящие письма» → «Новое письмо».
Локальные исходящие защищены Windows DPAPI; это не серверные черновики. Результат доступен в том же окне и списке исходящих.
«Принято SMTP» означает приём сервером, не подтверждённую доставку. При «Исход неизвестен» не повторяйте автоматически: проверьте папки и адресата. Автоматического повтора и скрытой отправки части адресатов при отказе остальных нет.
«Проверить Отправленные» только ищет серверную копию по Message-ID. Если копия не найдена, она может появиться позже. Отдельное «Сохранить копию» после просмотра создаёт копию в показанной папке, не отправляет письмо повторно.
Лимиты: до 50 получателей, 100000 символов тела, 10 вложений, каждый и суммарно до 25 МиБ, готовое MIME-письмо до 36 МиБ; дополнительно учитывается лимит SMTP-сервера. Не-ASCII имя перед @ (SMTPUTF8), HTML-редактор и серверные черновики пока не поддержаны.

ОБНОВЛЕНИЯ
MailBridge → «Обновления» → «Проверить обновления». Программа проверяет цифровую подпись сведений о выпуске; новый установщик сверяется по подписанным размеру и SHA-256. До проверки он не запускается.
Нажмите «Обновить» после просмотра изменений. Окно закроется; помощник дождётся завершения почтовых команд, заменит одну установку, проверит запуск и откроет программу снова. Настройки и история исходящих остаются отдельно.
В окне есть «Восстановить предыдущую версию». Старая версия может не поддерживать новые функции, но повторной отправки писем не будет.
При недоступности GitHub установленная программа продолжает работать. Почтовые данные и пароли не отправляются на GitHub.
Эта проверка подписи обновления отличается от доверенной подписи издателя Windows. Authenticode-подписи пока нет; предупреждения Windows возможны. Не отключайте защиту ОС ради установки.

ДАННЫЕ И ДИАГНОСТИКА
Пароль хранится в Credential Manager. «Отключить ящик» удаляет только текущую почтовую настройку/пароль MailBridge после вашего подтверждения; письма на сервере остаются.
Удаление программы сохраняет настройки, пароль и защищённые локальные исходящие. DPAPI-данные привязаны к Windows-пользователю; переносить их на другой ПК вместо отдельной настройки нельзя.
«Диагностика» показывает версию, ОС, TLS и результат обновления без пароля и тел писем. Отчёт можно сохранить локально и передать разработчику после просмотра.
Окно настройки не нужно держать открытым для чтения из ChatGPT. Для подтверждения исходящего письма откроется отдельный просмотр.

Подробности выпуска: https://github.com/okkiam/mailbridge-releases/releases

ДЛИННЫЕ ФАЙЛЫ И СКАНЫ В 0.8.1
Вложение до 50 МиБ, входящее MIME-письмо до 100 МиБ, PDF до 1000 страниц. Текст возвращается частями: по умолчанию 20000 символов и 10 страниц за вызов, с возможностью продолжения. До 8 млн символов за обрабатываемый документ/порцию страниц. Чтение выполняется в отдельном процессе до 120 секунд / 1 ГиБ; при превышении предложите разделить файл.
Можно попросить: «Прочитай вложенный скан, укажи сроки и номера страниц; если документ длинный, дочитай все части». Ошибки OCR возможны: суммы, реквизиты, даты и имена сверяйте с оригиналом. Картинка страницы PDF может быть сохранена для визуального изучения; это не заменяет фактический просмотр.
ZIP/EML открываются для выбора нужного файла, автоматического запуска вложений нет. RAR/7z, старый PPT, аудио/видео и все существующие форматы не поддерживаются. Доступные возможности и предупреждения сообщает коннектор.
Распознанный текст кешируется под защитой Windows DPAPI (до 256 МиБ, 100 записей, 7 дней). Файлы, сохранённые в папке чата, не шифруются приложением автоматически.
Лицензии компонентов находятся в app/licenses/reader-LICENSES.zip; соответствующие открытые исходники libiconv и рецепт сборки доступны в файле third-party-source.zip того же выпуска.
УДАЛЕНИЕ ЧЕРЕЗ CHATGPT
Пример: «Найди письма от указанного отправителя за 2026 год, покажи список и подготовь перемещение в Корзину». Агент выбирает точные письма и открывает локальный предпросмотр MailBridge; браузером почты он не управляет.
В просмотре проверьте ящик, исходную папку, Корзину, число и весь список. Поставьте галочку и сами нажмите «Переместить в Корзину». Окно MailBridge до этого можно держать закрытым: агент откроет его по необходимости. Агент не нажимает подтверждение за вас.
Кнопка «Удаление писем» открывает историю и подготовленные просмотры. «Проверить результат» уточняет результат без повторного перемещения. При неизвестном/частичном исходе автоматического повтора нет. Предпросмотр действует 24 часа; партия до 500 писем одной папки.
Это перемещение в Корзину по IMAP, не безвозвратное удаление. Корзина не очищается; освобождение места не гарантируется сразу. Восстановление письма средствами самой почты возможно, пока копия находится в Корзине; отдельной кнопки восстановления писем в MailBridge пока нет. «Восстановить предыдущую версию» относится к программе, не к письмам.

ОБЪЁМ ПИСЕМ
Примеры: «Покажи топ-10 отправителей в Рассылках по мегабайтам и по количеству, с долями»; «Сколько объёма занимают письма в каждой папке моего ящика?». ChatGPT получает сводку, рассчитанную MailBridge по отправителям и серверным размерам, без чтения тел и скачивания вложений.
Большая выборка дочитывается порциями. Промежуточный рейтинг помечается как неполный; готовый отчёт указывает папки/период/полноту. Копии в разных папках считаются отдельно; весь ящик включает также Отправленные, Спам и Корзину. Снимки по папкам последовательные, не одновременные.
MB = 1000000 байт. Это заявленный IMAP-сервером размер целого MIME-письма, не фактический диск/квота Mail.ru и не размер распакованных файлов. Доли относятся к обработанной выборке. До 50000 писем одной папки, до 250000 за отчёт; при превышении нужно сузить период/папки. Кеш отчётов защищён Windows DPAPI, до 7 дней/последние 20; продолжение действительно 24 часа.

ПЕРЕХОД СО СТАРОЙ ВЕРСИИ
Если стоит 0.5.1 и в ней ещё нет «Обновлений», один раз запустите новый установщик поверх прежней установки, сохранив её папку. Для версии 0.6.0 и новее доступна кнопка обновления из приложения. Настройки и пароль должны сохраниться. Испытание новой версии на втором реальном ПК остаётся отдельным шагом.
