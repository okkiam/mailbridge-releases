# MailBridge для Windows

Ваша почта для вашего ИИ: локальная программа для Mail.ru и установленного ChatGPT с режимом «Работа» и доступом к этому компьютеру.

[Скачать установщик](https://github.com/okkiam/mailbridge-releases/releases/latest/download/MailBridge-Setup.exe) · [Выпуски и инструкция](https://github.com/okkiam/mailbridge-releases/releases/latest)

Python и Office отдельно не нужны. После установки настройте свой ящик с отдельным паролем приложения Mail.ru и подключите плагин через окно MailBridge. Письма для анализа передаются в контекст ChatGPT, пароль остаётся в хранилище Windows.

Доступны чтение, поиск по папкам, TXT/PDF/DOCX/XLSX и подготовка новых писем/ответов. Отправку подтверждает человек после полного локального просмотра; автоматического повтора при неизвестном исходе нет. Обновления проверяются из MailBridge и устанавливаются после согласия с проверкой цифровой подписи выпуска.

Испытана Windows 11 x64. Сканы без OCR, старые DOC/XLS, макросы, SMTPUTF8 и серверные черновики пока не поддержаны. Формулы XLSX не пересчитываются. Подпись обновления не является Authenticode-подписью Windows; предупреждения ОС возможны.

Здесь размещаются только установщики, подписанные сведения о выпусках и пользовательские инструкции. Исходники, внутренний контекст, почта, пароли и ключи подписи не публикуются.
